## Reproducible Harness

Added `scripts/p12-server-smoke.sh`. It:

- accepts `paper` or `folia`, a server directory, and the current artifact;
- refuses to use an occupied default port;
- temporarily installs the artifact and restores the previous plugin JAR on exit;
- captures output under `/tmp/vanticheat-p12`;
- verifies VAntiCheat enable and disable messages;
- explicitly states that it performs no player validation.

Example:

```bash
scripts/p12-server-smoke.sh folia /home/shadi/test-server-folia target/vanticheat-0.1.0-SNAPSHOT.jar 45
```

The Folia smoke harness was executed successfully. The existing Paper process on port 25571 was correctly protected from replacement.
