## B. Reproduction

## C. Root Cause

`PaperSignProbeTransport.candidates` only searched four locations at
`playerY - 1`. A normal vanilla player stands on solid terrain, so all four
locations were non-air. `placeNext` exhausted the candidates and intentionally
returned `ProbeResponse.error`; this was a transport placement failure, not a
client response or evaluator failure.
