# Archive: VAntiCheat 1.3.x documents

(`com.hexa.vanticheat`) and do **not** apply to VAntiCheat 0.1.0.

The current product is documented in the repository `README.md`:

blocklist. See the README for the supported topology, the separate Fabric
client verifier, and the explicit security limitations.
